Rubrica · the keys desk

Your keys, where they hide.

Token-based tools need a key from your already-logged-in browser. Here’s exactly where each platform keeps it. A token is like your password — copy it once, keep it private, never paste it into anything you don’t trust.

A —

Browsers & DevTools

Open DevTools

On Windows/Linux: F12 or Ctrl+Shift+I. On macOS: Cmd+Option+I. Right-click → “Inspect” works too.

Enable network log

In the Network tab, tick Preserve log. Hard-refresh the reader page (Ctrl/Cmd+Shift+R) so the book’s API calls appear as they load.

Privacy first
A token grants access to your books. Folio’s in-browser tools keep it in the page’s memory only. On shared machines, close the tab when you’re done.

Local Storage / Session Storage — find under Application → Storage → Local Storage → https://platform. Look for keys like token, jwtToken, auth_token, tokenId.

Cookies — Application → Storage → Cookies → https://platform. Sometimes the value hides here (bSmart’s _bsw_session_v1_production).

Response headers — in the Network tab, open an API call and read the Response JSON or the Headers. Many platforms return their token in the login response body.

B —

Per platform

HUB Scuola / Young / Kids — token or email & password

Easiest: don’t hunt for a token at all — the Reader logs in with email & password directly. If you prefer a token: log in at hubscuola.it, open the reader, DevTools → Network → ms-api.hubscuola.it call → Request Headers → Token-Session. It’s usually valid a long time.

MyLim (Loescher) — JWT

Log in at mylim.loescher.it. DevTools → Application → Local Storage → https://mylim.loescher.it → the key token (a JWT, starts eyJ…). Paste it in the MyLim Reader.

bSmart — session cookie

Log in at my.bsmart.it. DevTools → Application → Cookies → https://my.bsmart.it → copy _bsw_session_v1_production. Pass it to the CLI with --cookie.

DiBooK (Laterza) — JWT

Open a book in the reader at dibooklaterza.it. DevTools → Application → Local Storage → copy jwtToken. Feed it to the CLI with --jwt.

Scuolabook / pdfgrabber — generated token, store it safely

pdfgrabber registers a token for you (r in its menu). Scuolabook is strict about logins — keep that token in a text file. Never machine-share it.

Everything else — email & password suffices

Zanichelli, Pearson, Sanoma, Educadhoc, WSET and the HUB Python tool log in on their own. Just run them and type your credentials at the prompt — no token hunting needed.

Handle with care. A token is a live credential. This site stores nothing, sends nothing, and has no backend. Anyone asking you to upload your token to a server is a scam — a real downloader will always run where you are.
