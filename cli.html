Banco di lavoro · the CLI desk

Run them on your machine.

Every tool below lives in its own folder in this repository, MIT licensed, README intact. Two flavours: Node (install with npm i, run with node index.js) and Python (pip install -r requirements.txt).

First, grab your keys →

A —

Node tools

Zanichelli — one tool, two reader backends (Kitaboo + BookTab) 
cd zanichelli-downloader
npm i
node .

Prompts for email and password. Produces PDF (standard books), EPUB (liquid books) or, where pages are not served as PDF, downloads XPS files and prints instructions. Supports a --no-cleanup style flag — run node . --help. Needs Node 18+.

bSmart — also handles DigiBook24 / EdiErmes 
cd bSmart-downloader
npm i
node index.js

Paste your session cookie (_bsw_session_v1_production from DevTools). Useful flags: --site bsmart|digibook24, --cookie, --bookId, --concurrency, --md5, --resources. If the merger hiccups, retry with node index.js --pdftk.

DiBooK (Laterza) — PDFs protected with a derivable password 
cd dibook-downloader
npm i
node .

Paste your jwtToken from Local Storage and the ISBN. Each page PDF ships password-protected; the tool strips that password and merges. Requires Java and the pdftk-all.jar (see README), or use --useSystemExecutable with a system pdftk.

Educadhoc (Hachette) — JPegé & real-browser rendering 
cd educadhoc-downloader
npm i
node index.js -u you@mail.it -p 'your-password' -e 978XXXXXXXXXXX

JPEG pages are embedded directly; XHTML pages are rendered through Puppeteer (a headless Chromium) and merged. Run npx puppeteer browsers install chrome once if the renderer asks. Options: -u / -p / -e / -o.

Hoepli (public demo books) 
cd hoepli-demo-downloader
npm i
node index.js --url "https://…/demo/viewer/"

No login. Renders substrate images + text layer and exports a clean PDF with Puppeteer. Flags: --url, --output, --delay.

HUB Young / Kids (token) — the same engine as our Reader 
cd hub-young-downloader-main
npm i
node index.js -p hubyoung -v 1234 -t 'your-token'

Flags: -p hubyoung|hubkids, -v volumeId, -t token, -f out.pdf. Reads the SQLite publication index, downloads each chapter zip, merges to PDF. Prefer the in-browser Reader — it runs the same pipeline without installing anything.

Sanoma · My Digital Book — SVG pages via Inkscape 
cd sanoma-downloader
npm i
node index.js --id you@mail.it --password 'your-password'

Books arrive as ZIPs of SVG pages. Inkscape must be installed and on PATH; the tool auto-detects its version. Flags: --gedi (pick a single book), --output, --no-download to re-process a cached zip. Requires the “My Digital Book” app to be activated once.

WSET Global (Kitaboo wine & spirits ebooks) 
cd WSETGlobal-downloader
npm i
node .

Email/password against the Kitaboo backend; reassembles the book spine as a PDF. Note: logs you out of existing device sessions — acceptable, since there are no other ways to build offline files. May be glitchy on macOS; test on Linux.

B —

Python tools

Pearson eText — device registration, RSA/AES decrypt, EPUB→PDF 
cd pearson-downloader
./setup.sh            # creates the venv, installs deps + Playwright Chromium
.venv/bin/python3 main.py

The most productised Python tool: progress bars, device registration, AES-CBC decryption of the packaged EPUB, then renders each XHTML page to PDF with Playwright. If login fails, accept the terms once in the Pearson Reader+ app and retry.

HUB Scuola (Python) — email & password 
cd hubscuola-downloader
pip3 install -r requirements.txt
python3 main.py you@mail.it 'your-password'

Logs in via the Mondadori JSONP endpoint, lists your library and merges each book with PyPDF2. Prefer the in-browser Reader — same flow, zero install.

pdfgrabber — one script, thirteen services 
git clone https://github.com/djlight/pdfgrabber
cd pdfgrabber
pip3 install -r requirements.txt
python3 main.py

Select r to register a token, then d to download. Covers Scuolabook, MyLim, Pearson eText & Reader+, bSmart, HUB Scuola, MEE2, easyeschool, Zanichelli Booktab & Kitaboo, Oxford Learner’s Bookshelf, DiBooK, Raffaello. Needs playwright install chromium for Kitaboo/Reader+ EPUBs. Scuolabook: strictly limited logins (2 devices · 2 deletions/year) — store the saved token somewhere safe. Best-quality PDF & TOC on MyLim and Scuolabook.

C —

Good to know

Permissions & tooling

  • Node 18+ for the Node tools. Check with node -v.
  • Java + pdftk-all.jar only for DiBooK.
  • Inkscape on PATH only for Sanoma.
  • Puppeteer/Playwright Chromium only for Educadhoc, Hoepli, Pearson.

First-time token hunting

Token-based tools need a key from your browser’s DevTools. The Keys desk shows exactly where each platform hides its token — copy once, paste safely, and never share it.
